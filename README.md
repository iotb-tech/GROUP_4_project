# 🍽 MealMenu

A single-page web app for searching and exploring meals from around the world.

## Features
- 🔍 Live meal search with debouncing
- 📋 Detailed meal view with ingredients and instructions
- ❤️ Save favourite meals (persisted with localStorage)
- 📱 Responsive layout built with Tailwind CSS

## Tech Stack
- Vite + TypeScript
- Tailwind CSS
- TheMealDB API

## Getting Started

git clone <your-repo-url>
cd GROUP_4_project
npm install
npm run dev
